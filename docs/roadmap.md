# Roadmap

This page outlines the major milestones planned for Eld. Timelines are directional and may shift as the network evolves.

## Completed

### 2026

#### Testnet Launch

- Testnet launch of eld node cluster

## Plan

### 2026

#### Testnet

- Extend tester whitelist
- Patches for performance and vulnerabilities
- Improved resume and sync logic
- Improved documentation
- Testnet with open testing
- Update github with open sourced code

#### Features & integrations

- **Namespace sale** — reserve your own namespace on Eld (registration and uploads are available; see [Custom namespaces](./namespaces))
- Smart contract support, incl tokens, NFTs and Defi
- Solana testnet to Eld bridge

#### Economics

- Fee model, rewards, total supply, and related token economics for ELD

#### Mainnet Launch

#### Features & integrations
