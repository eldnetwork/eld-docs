# Welcome to Eld

Eld is a blockchain designed as an ephemeral, content-addressed scratchpad — a lightweight, fast, temporary memory layer accessible from any device, including mobiles and everyday hardware. 

Just like a physical scratchpad, Eld lets you store and retrieve data ephemerally: it's there when you need it, but it naturally fades or gets pruned over time rather than burdening the network indefinitely.

Any device can join the network and contribute storage, turning idle phones, laptops, or edge nodes into active participants that provide temporary, decentralized capacity without requiring massive permanent commitments.

Inspired by protocols like LBRY, which democratized content publishing and discovery, Eld flips the "forever-data" paradigm seen in permanent blockchain archives. Instead, it embraces ephemerality as a feature: many real-world scenarios demand data that is intentionally short-lived, low-cost, and garbage-collectable.

Key use cases include:

- Temporary caching & sharing for live events, real-time collaboration, or flash sales, where data expires after hours/days.
- Ephemeral messaging, chat attachments, or social feeds that auto-purge to respect privacy and reduce storage bloat.
- Quick prototyping, draft sharing, or one-time computations, e.g., AI inference results, session logs, or debug traces.
- IoT sensor bursts or edge analytics where fresh data matters more than archival permanence.
- Disposable credentials, temporary proofs, or short-term coordination in decentralized apps, e.g., event tickets, flash loans metadata, or live bidding states.
- Content-addressed scratch space for agents/AI — storing intermediate results, thoughts, or tool outputs that only need to live for a task's duration.

Looking ahead, Eld aims to extend this foundation to support compute and autonomous agents running on any device, or provide lightweight, ephemeral AI agent storage — enabling mobile-first, decentralized intelligence without relying on always-on servers or eternal blockchains.

In short: Eld is the blockchain equivalent of a sticky note wall or whiteboard session — fast, collaborative, accessible everywhere, and gloriously temporary.
